# LogiTrainer

Une petite application web en français pour entraîner sa mémoire avec des
séquences de palets colorés.

## Jouer

Ouvrez `index.html` dans un navigateur. Aucun paquet ni étape de compilation
n'est nécessaire.

Choisissez une longueur de départ de 3, 4 ou 5 palets, puis lancez la partie.
Observez les palets qui s'illuminent et reproduisez leur ordre. Chaque réussite
ajoute un palet à la séquence. Le record est conservé dans le navigateur.
